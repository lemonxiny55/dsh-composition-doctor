## Release blockers fixed

The [initial run](https://github.com/lemonxiny55/dsh-composition-doctor/actions/runs/37186848590) failed on Ubuntu Node 24 because the nested DSH install joined Doctor's pnpm workspace. It modified the root dependency resolution instead of creating the requested isolated binary, contaminating static/unavailable tests. The fix is `--ignore-workspace` on that single test-artifact install. It retains `--ignore-scripts` and does not disable any test.

A clean Windows checkout also exposed LF-versus-CRLF differences in a checked-out dump golden. The real harness comparison now normalizes transport newlines on both sides. Exact config, provenance, version, layer-order, replacement and unmatched-target assertions remain intact. The Windows reproduction first failed on this difference, then passed the full gates and packed smoke with the fix.

Both fixes are in `063d7a8`, affecting only the CI workflow and its real-DSH test harness. Product scope is unchanged.
